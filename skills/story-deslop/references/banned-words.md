## 句式与组织信号

| 信号 | 可检索形式 | 需确认的语义问题 |
|---|---|---|
| 否定翻转 | 不是 A，（而）是 B；不是 A，不是 B，只是 C；没有 X，没有 Y，只有 Z | 是否先否定无人在意的靶子，再宣布结论？纠错、辩解和排除猜测也可能需要对比 |
| 工整并列 | 跨段“不是／也不是／只是”；有的……有的……；一边……一边……；至于 X 不 X，怎么 X；不 V A，不 V B | 是否重复同一意思或照抄提纲字段？排比也可承担递进与人物声线 |
| 万能状语、声线 | 带着一丝……；声音不大，却带着……；语气毫无波澜；平静得像在念…… | 是否只贴抽象态度，没有可辨的说话内容或声音信息？ |
| 引号强调 | “机会”“答案”“蜕变”等普通词反复加引号 | 是否虚造术语或替读者划重点？引用、代号、场内消息与反讽另判 |
| 解释结论链 | 这意味着；真正重要的是；之所以……是因为；由此可见；他终于明白 | 是否重复读者已得到的意思，或把必要过程概括掉？ |
| 抽象收束、预告 | 命运／宿命＋齿轮／棋局／獠牙／安排；从这一刻开始；反击才刚刚开始；她不知道的是；多年以后 | 是否只宣告分量，或越过本次揭露边界？回顾、全知与题材承诺按文风判断 |
| 电报体、动作清单 | 连续孤立短句；抬手、取过、放下、转身；动作后反复“了下／了一下” | 是否丢失动作方向、对象和连接，或把无关步骤全部拍出？ |
| 公文腔 | 基于、当前、进一步、推进、落实、从而、诚然、不得、须 | 是否与人物、年代和载体语域不合？公告、规则和职业表达可有意采用 |

## 套词与套式反应信号

以下组合在跨场景机械复现、成片堆叠或只替情绪贴标签时优先复核；孤立出现不判错。

| 类别 | 检索词例 |
|---|---|
| 弱化与装饰 | 微微、淡淡、缓缓、轻轻、一丝、一抹、些许、几分、隐约、微不可察、几不可闻 |
| 通用反应 | 深吸一口气、眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩、指节泛白、指尖轻叩、攥紧袖口、目光移开 |
| 通用心理 | 心头一震、心中一动、心中暗道、心底泛起、心中涌起一股、心里某个地方软得一塌糊涂 |
| 空泛定性 | 不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、前所未有、散发着一股……气息／气场 |
| 模板比喻 | 如潮水般、犹如疾风骤雨、仿佛能……一般、像命运的齿轮、像在宣判、眼里淬了毒 |
| 自动过渡 | 映入眼帘、只见、此时此刻、不由自主、情不自禁、自然而然、话锋一转、取而代之的是 |

“她感到”“意识到”“知道”“原来”可以准确表达感受、判断和发现；“仿佛／好像／似乎”可以限定视角置信度；“坚定／冰冷／深邃”可以是准确描述。“突然／瞬间／猛地”也可能承担真实突发或时间压缩。只凭这些词不能认定告知式心理、模板比喻或偷懒。

## 提示名称索引

脚本提示供定位，不能替代语义结论。`formulaic-parallelism` 对应对比与并列，`quote-emphasis-tic` 对应引号强调；`cliche-density-tic`、`metaphor-density-tic` 对应套词与比喻聚集；`stock-reaction-tic`、`micro-action-tic`、`action-list-tic` 对应反应与动作；`abstract-summary-tic`、`reasoning-chain-tic` 对应总结解释；`overcompressed-prose-tic`、`low-connective-density-tic` 对应过度压缩；`system-notice-formality-tic` 对应载体语域。是否构成问题、如何修复及获准保留，由本次方法与文风裁决确定。

标点、句长、段落疏密和对话占比均不在此设置统一指标。不通过同义词轮换、错误用字、英文点省略号或机械补动作规避提示。
